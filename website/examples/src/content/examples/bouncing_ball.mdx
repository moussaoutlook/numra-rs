A ball falling under gravity, bouncing off the floor with coefficient
of restitution `e`. The continuous dynamics are trivial; the
interesting bit is the discrete reset at each ground contact.

```text
y'' = -g
v_after = -e * v_before     at every event
```

The example chains integration segments — one per bounce — and uses
the dense-output interpolant to locate ground contact precisely
between steps. It's the canonical introduction to numra's
event-detection API.

Run it:

```bash
cargo run --release --example bouncing_ball
```
