The Van der Pol oscillator is the canonical stiff-ODE test problem.
For small `μ` the system is non-stiff and any explicit solver works
fine; for large `μ` (e.g. `μ = 1000`) it develops sharp transitions
between slow and fast dynamics, and an implicit method becomes
necessary.

```text
x'' - μ(1 - x²)x' + x = 0
```

This example sweeps `μ ∈ {1, 10, 100}` with both `DoPri5` (explicit)
and `Radau5` (implicit), printing step counts and wall-clock so the
crossover is observable.

Run it:

```bash
cargo run --release --example van_der_pol
```
